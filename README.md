## Projects

### 1. Loan Default Analysis

**Tools:** Power BI | DAX | Power Query | SQL Server | Python

An end-to-end Business Intelligence project analyzing **255,347 loan records** to understand loan default patterns, borrower characteristics, financial profiles, and risk indicators.

#### Key Areas

- SQL-based data validation and analysis
- Missing-value and duplicate checks
- Python-based data cleaning and exploratory analysis
- Power BI data modeling and transformation
- DAX-based calculations and KPI reporting
- Interactive Power BI dashboards
- Loan default and financial risk analysis

### 2. Housing Market Analysis

**Tools:** Power BI | DAX | SQL | Python

An end-to-end data analytics project analyzing **100,000 housing transactions** to understand property pricing, regional sales performance, property characteristics, and market trends.

#### Key Areas

- SQL-based data validation and data-quality checks
- Data cleaning and transformation
- Python exploratory data analysis
- Regional and property-level analysis
- Power BI data modeling and visualization
- KPI-focused reporting
- Housing sales and pricing analysis
